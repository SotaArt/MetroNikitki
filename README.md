# МетроПати

Детская веб-игра (PWA) про метро: React + TypeScript + Vite.

## Возможности

- Игровой процесс с пассажирами, вагонами, уровнями и посадкой
- Адаптация под мобильные устройства/Android и PWA-режим
- Офлайн-работа после установки (Service Worker, precache)
- Стартовый экран с кнопкой «Играть» (запуск игры/генерации после нажатия)
- Таймер на паузе по умолчанию (можно включить вручную)

## Стек

- React
- TypeScript
- Vite
- vite-plugin-pwa (`injectManifest`)

## Локальный запуск (разработка)

```bash
npm install
npm run dev
```

## Сборка

```bash
npm install
npm run build
```

Готовая статическая сборка находится в папке `dist/`.

## Офлайн / PWA

- Для корректной работы Service Worker и установки PWA требуется безопасный контекст: `https://` или `http://localhost`.
- Для работы офлайн без локального сервера приложение нужно разместить по HTTPS и установить как PWA (или упаковать в Android-приложение).
- После обновления версии может потребоваться обновление кеша/переустановка PWA.

## Деплой

Репозиторий содержит исходный код и папку `dist/` (собранную версию), что позволяет публиковать статическую версию через Git-хостинг/Pages.
